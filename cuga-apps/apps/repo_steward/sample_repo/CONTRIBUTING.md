# Contributing to demo-widget

Thanks for your interest. This is a small open-source library for rendering
interactive widgets.

## Commit format

We use [Conventional Commits](https://www.conventionalcommits.org/). PR titles
must start with one of: `feat:`, `fix:`, `docs:`, `refactor:`, `perf:`,
`test:`, `chore:`, `ci:`, or `BREAKING CHANGE:`.

## Issues

- Bug reports must include: version, reproduction steps, expected behavior,
  actual behavior.
- Feature requests: describe the use case first, not the implementation.

## Security

Do not file public issues for security vulnerabilities. See `SECURITY.md`.
